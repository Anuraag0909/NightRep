# 🌌 NightRep: Decentralized Privacy-Preserving Reputation System

[![Midnight Network](https://img.shields.io/badge/Midnight-Network-blue?style=for-the-badge)](https://midnight.network/)
[![React](https://img.shields.io/badge/React-19-61dafb?style=for-the-badge&logo=react)](https://react.dev/)

**NightRep** is a privacy-first decentralized application (DApp) built on the **Midnight Network**. It allows users to securely build, verify, and increment an on-chain reputation score without ever exposing their underlying trade histories, exchange secrets, or receipts to the public ledger.

## 🔒 Privacy Claim & Zero-Knowledge Architecture

NightRep leverages Midnight's powerful zero-knowledge (ZK) circuits to guarantee user privacy while maintaining public trust:

1. **What remains private**: The original secret receipt string generated by the exchange. It is never transmitted, stored, or revealed in plain text on the blockchain.
2. **What is committed to the ledger**: A cryptographic hash (nullifier) of the receipt is stored in the `valid_receipts` and `used_receipts` ledgers strictly to prevent double-spending.
3. **What the ZK Proof demonstrates**: The `record_trade` circuit generates a mathematical proof demonstrating that the user possesses a secret receipt mapping to a valid, unused nullifier in the ledger—all without revealing the receipt itself.
4. **What is selectively disclosed**: Only the user's public address and the approved trade amount are publicly disclosed and stored in the `scores` ledger to transparently update their reputation score.
5. **What the user does NOT reveal**: The exact details of their trade, the specific exchange receipt string, and any linkage between multiple receipts over time.
6. **Local Proof Generation**: Proofs are generated *locally* on the user's machine via the Lace Wallet extension (utilizing the DApp Connector Proof Provider). Raw secret data never leaves the user's secure local environment.

## ⚙️ Technical Stack & Features

- **Frontend**: React 19, Vite, TypeScript, Framer Motion (for dynamic UI).
- **Wallet Integration**: Full Lace Wallet support (connect/disconnect flows) via `@midnight-ntwrk/dapp-connector-api`.
- **Midnight SDK**: Built using Midnight.js `v4.1.1`.
- **Smart Contract**: Written in Compact (`>= 0.23`), featuring shielded state management.
- **Local ZK Proving**: Strictly enforces client-side ZK proof generation (`api.getProvingProvider`), eliminating the need for a centralized proof server.

- **Circuits**: 
  - `issue_receipt`: Authorized by an exchange to create a valid receipt nullifier.

## 🚀 Getting Started

### 1. Wallet Setup
1. Install the **Lace Wallet** browser extension and configure it for the **Midnight Preview** network.
2. Ensure your wallet is funded with `tNIGHT` from the Midnight Faucet.
3. In the NightRep UI, click **"Connect Lace"** in the top right corner and approve the connection.

### 2. Running Locally
Clone the repository and install dependencies:
```bash
npm install
cd frontend
npm install
```

Create a `.env` file in the `frontend` directory:
```env
VITE_NETWORK=preview
VITE_INDEXER_URL=https://indexer.preview.midnight.network/api/v4/graphql
VITE_INDEXER_WS_URL=wss://indexer.preview.midnight.network/api/v4/graphql/ws
VITE_CONTRACT_ADDRESS=f2776a7cd0a51aaeadc7b04aa921ef5dc49516f699707cf746ffec8682b608b9
```

Start the development server:
```bash
npm run frontend:dev
```

## 🌐 Deployment Guide (Vercel)

This frontend is fully optimized and pre-configured for instant Vercel deployment via `vercel.json`.

1. Push this repository to GitHub.
2. Import the project into your Vercel account.
3. In the Vercel dashboard, add the four environment variables listed in the `.env` section above.
4. Click **Deploy**. Vercel will automatically install all root and frontend dependencies, compile the app, and generate your live demo link!
